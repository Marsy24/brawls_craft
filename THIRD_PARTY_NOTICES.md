# Assets and dependencies

All SVG artwork in `src/art/art.ts`, procedural world terrain, original names and synthesized sound effects were authored for this project. There are no downloaded Warcraft/Blizzard assets, music, logos, character names, icons or fonts. Fantasy references concern broad genre direction only.

Runtime dependency: Phaser 3.90.0, MIT license: https://github.com/phaserjs/phaser/blob/v3.90.0/LICENSE.md
Build/development dependencies are listed with pinned versions in package.json and package-lock.json; their licenses remain in their npm distributions. System fonts are used; no web-font downloads. Symbols use the user's font fallback.

Implementation reference: Phaser Scene lifecycle and Scale Manager official documentation:

- https://docs.phaser.io/phaser/concepts/scenes
- https://docs.phaser.io/phaser/concepts/scale-manager
