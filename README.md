# Пепельный Завет · Brawls Craft

Браузерная 2D Fantasy Action RPG в оригинальном мире. TypeScript, Vite, Phaser 3. Интерфейс на русском, одиночная игра, обязательного backend нет.

**Статус: первая реализованная версия / release candidate.** Боевая модель, интерфейсные сценарии и production-сборка проверены автоматически. Реальный браузерный плейтест, визуальная приёмка и измерение FPS в этой среде не проводились. Это явно отделено от результатов headless-симуляций.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.19) и npm.

```bash
npm ci
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173. Создайте героя, выберите первую экспедицию и нажмите «Начать экспедицию». Первая победа открывает следующую миссию.

```bash
npm test             # unit + integration + DOM checks
npm run balance      # DPS, билды, EHP, XP и 100000 открытий реликвий
npm run simulate     # пять классов × пять миссий, программный игрок
npm run build        # строгая проверка TypeScript и production-сборка
npm run preview      # локально открыть собранную версию
```

Каталог `dist/` можно разместить на любом статическом HTTP-хостинге. `base: './'` поддерживает размещение в подпапке. Открытие `index.html` напрямую через `file://` не поддерживается. Phaser загружается отдельным чанком при первом запуске боя; предупреждение Vite о размере vendor-чанка известно (~340 KB gzip) и не является ошибкой сборки. В production приложение не обращается к внешним API, шрифтам или CDN.

## Что реализовано

- Пять классов: воин, маг, охотник, **некромант**, **ассассин**. Двадцать активных способностей, классовые пассивные эффекты, тридцать талантов в десяти ветках.
- Вид сверху, WASD и мышь, реальные столкновения, снаряды, области урона, контроль, щиты, яд, рывки и ограниченные по времени призывы.
- Пять экспедиций: зачистка леса, босс в руинах, волны в пещерах, защита маяка и финальный босс святилища. Два уровня сложности и дополнительные цели.
- Два босса с фазами и предупреждениями атак; семь обычных/элитных архетипов врагов, A\* вокруг препятствий и переключение внимания.
- Уровни 1–15, четыре очка талантов на уровнях 2/5/8/11, бесплатный сброс. Три слота экипировки, пять редкостей, сравнение предметов и разбор за золото.
- Пятнадцать оригинальных косметических обликов в трёх вариантах силуэта оружия на класс и пяти палитрах редкости. Реликвии за активность/золото, открытые вероятности, гарантия редкой награды, осколки за дубликаты и создание выбранного облика. Никаких платежей и боевых преимуществ от косметики.
- До десяти персонажей, общая коллекция, имя/облик/цвет, сохранения с проверкой данных и резервной копией, импорт/экспорт JSON, настройки звука и анимаций.
- Оригинальная SVG-графика и синтезированные звуки. Материалы Blizzard не используются.

## Управление

| Клавиши              | Действие                              |
| -------------------- | ------------------------------------- |
| WASD / стрелки       | Перемещение                           |
| Мышь + удержание ЛКМ | Наведение и базовая атака             |
| 1–4                  | Способности                           |
| Space                | Уклонение, 0,25 с неуязвимости        |
| E                    | Зелье восстановления, откат 22 с      |
| I / C / K            | Инвентарь / герой / таланты, с паузой |
| Esc                  | Пауза / продолжить                    |

Красные области показывают будущие атаки. У кольцевой атаки Смотрителя внутренний круг безопасен. При потере фокуса бой ставится на паузу. Изменение экипировки и талантов доступно между миссиями, чтобы характеристики не менялись посреди боя.

## Сохранения

Ключ localStorage: `brawls-craft:save:v1`; предыдущая проверенная версия — `:backup`. Сохраняются завершённые результаты и действия в лагере, а не незавершённый бой. Импорт валидируется до замены, текущая версия предварительно скачивается. При ошибке хранилища интерфейс предлагает экспорт. Сохранения привязаны к origin (домену/порту) браузера: переносите их через экспорт, если меняете адрес.
